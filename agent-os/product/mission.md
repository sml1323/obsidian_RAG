# Product Mission

## Pitch
Obsidian RAG PARA Companion is a personal knowledge management and execution tool that helps heavy Obsidian note takers revive and act on their second brain by providing incremental RAG chat, PARA project health visibility, and spaced repetition nudges.

## Users

### Primary Customers
- Obsidian power users building a second brain: need fast recall across fragmented notes.
- Solo builders using PARA for side projects: want a quick view of stalled or aging work.

### User Personas
**Focused Obsidian Creator** (25–45)
- **Role:** Developer, maker, or knowledge worker managing projects and learning in Obsidian
- **Context:** Juggles multiple PARA projects and reference notes across devices
- **Pain Points:** Hard to find prior decisions, projects go stale unnoticed, forget key concepts over time
- **Goals:** Get trustworthy answers from existing notes, keep projects moving, and retain core concepts with light-touch review

## The Problem

### Fragmented notes block recall and momentum
Thousands of Obsidian files become hard to search, so decisions and ideas get lost. Stalled projects and forgotten concepts waste effort and slow delivery.

**Our Solution:** Turn the vault into an incremental RAG index with PARA-aware progress visibility and spaced review prompts, so knowledge stays actionable.

## Differentiators

### Obsidian-native, PARA-aware, and memory-first
Unlike generic AI chat or task tools, we provide incremental embeddings tied to file changes plus PARA project freshness and spaced repetition cues. This results in answers grounded in your own notes and timely prompts to revive aging work.

## Key Features

### Core Features
- **Incremental RAG Chat:** Ask natural questions and get grounded answers from your vault with near real-time updates when notes change.

### Collaboration Features
- **PARA Project Dashboard:** See project progress and last-updated signals by folder so you can spot and revive neglected work quickly.

### Advanced Features
- **Spaced Repetition (Memory Boost):** Receive tag-based review prompts and randomized cards aligned to the forgetting curve to keep key concepts fresh.
