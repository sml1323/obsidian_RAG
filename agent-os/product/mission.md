# Product Mission

## Pitch
**Obsidian AI Pilot**은 개인 지식 관리 도구로, 옵시디언 파워 유저가 자신의 로컬 노트를 복잡한 설정 없이 즉시 AI 지식 베이스로 전환하여 탐색하고, 프로젝트 진척도를 체계적으로 모니터링하며, 과거 기록을 효과적으로 복습할 수 있도록 돕습니다.

## Users

### Primary Customers
- **지식 관리 파워 유저**: 옵시디언에 수백~수천 개의 노트를 축적하며, 이를 체계적으로 활용하고 싶어하는 사용자
- **프로젝트 중심 개인 생산성 추구자**: PARA 방법론 등을 활용해 여러 프로젝트를 병행하며, 진행 상태를 한눈에 파악하고 싶은 사용자

### User Personas
**지식 탐험가 민수** (30대)
- **Role:** 스타트업 개발자 / 사이드 프로젝트 운영자
- **Context:** 기술 블로그, 학습 노트, 프로젝트 아이디어를 옵시디언에 기록하며 3년간 1,500개 이상의 노트 축적
- **Pain Points:** 과거에 정리한 내용을 찾기 어렵고, 프로젝트가 방치되기 쉬우며, 배운 내용을 금방 잊어버림
- **Goals:** AI와 대화하며 자신의 지식을 빠르게 탐색하고, 방치된 프로젝트를 발견하며, 과거 기록을 자연스럽게 복습

## The Problem

### 축적된 지식의 사장(死藏)
옵시디언 사용자는 방대한 노트를 축적하지만, 시간이 지나면서 과거 기록을 탐색하기 어렵고, 진행 중인 프로젝트는 방치되며, 학습한 내용은 망각됩니다. 이로 인해 가치 있는 개인 지식이 활용되지 못한 채 묻혀버립니다.

**Our Solution:** 로컬 노트를 실시간 임베딩하여 AI와 자연어로 탐색하고, PARA 기반 프로젝트 현황을 시각화하며, 랜덤 복습 기능으로 과거 기록을 주기적으로 상기시킵니다.

## Differentiators

### 로컬 우선 & 제로 설정
여느 RAG 솔루션과 달리, 복잡한 데이터 파이프라인이나 클라우드 업로드 없이 옵시디언 볼트를 지정하면 즉시 AI 대화를 시작할 수 있습니다. 이로 인해 프라이버시를 유지하면서도 첫 사용까지의 시간을 분 단위로 단축합니다.

### PARA 네이티브 통합
일반 노트 앱 AI와 달리, Project/ 폴더 구조를 인식하고 방치된 프로젝트와 달성률을 자동으로 추적합니다. 이를 통해 사용자는 별도의 프로젝트 관리 도구 없이 옵시디언 내에서 진척도를 파악할 수 있습니다.

## Key Features

### Core Features
- **Instant RAG Chat:** 자신의 노트를 기반으로 AI와 자연어 대화를 나누며, "프로젝트 A 관련 노트 요약해줘"와 같은 질문에 즉시 답변을 받습니다.
- **PARA Project Monitor:** Project/ 폴더 내 프로젝트들의 수정일, 달성률을 대시보드에서 한눈에 확인하고, 한 달 이상 방치된 프로젝트를 시각적으로 경고받습니다.

### Productivity Features
- **Smart Reviewer:** "오늘의 복습" 기능으로 랜덤하게 선별된 노트를 제시받아, 과거에 기록한 아이디어와 학습 내용을 자연스럽게 상기합니다.

### Advanced Features
- **Hybrid Model Support:** Ollama(로컬)와 OpenAI/Gemini(클라우드) 중 선택하여, 프라이버시와 성능 사이에서 유연하게 균형을 맞춥니다.
- **Cross-Platform Ready:** 웹 PoC로 시작해 Tauri 기반 Mac 앱으로 확장, 데스크톱 환경에서 네이티브 경험을 제공합니다.
